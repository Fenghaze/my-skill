# 增强对话规划技能

## 概述

本技能通过严谨的设计树方法论增强规划模式下的规划过程。它系统性地探索需求、提出详细问题、并确保完整的功能规范，从而最小化从设计到实现过程中的 bug。

## 使用时机

当以下情况时自动触发此技能：
1. 用户进入规划模式进行软件设计任务
2. 用户请求功能或系统的实施规划
3. 用户询问架构设计或系统规划

## 设计树方法论

设计树将需求从高层目标分解为具体的、可测试的规范：

```
目标（用户目标）
  └─ 领域分析
       └─ 用例场景
            └─ 功能点
                 └─ 需求细节
                      └─ 边界情况
                           └─ 异常处理
```

## 规划工作流程

### 阶段1：深度需求收集

**在以下类别中提出详细问题：**

1. **业务背景**
   - 我们要解决什么问题？
   - 用户是谁？
   - 成功指标是什么？

2. **功能需求**
   - 核心功能有哪些？
   - 有哪些边界情况？
   - 错误时应该如何处理？

3. **非功能需求**
   - 性能要求（延迟、吞吐量）
   - 可扩展性考虑
   - 安全要求
   - 可用性要求

4. **集成点**
   - 外部 API/依赖
   - 数据源
   - 需要集成的现有系统

5. **约束条件**
   - 技术约束（语言、框架）
   - 时间/预算约束
   - 团队专业能力

### 阶段2：设计树展开

对每个功能进行系统性展开：

```
功能：[功能名称]
├─ 主路径：[正常流程描述]
├─ 替代路径：[替代流程]
├─ 错误场景：
│   ├─ [错误类型1] → [恢复操作]
│   ├─ [错误类型2] → [恢复操作]
│   └─ ...
├─ 边界情况：
│   ├─ [边界情况1] → [预期行为]
│   ├─ [边界情况2] → [预期行为]
│   └─ ...
├─ 输入验证：
│   ├─ [字段1]：[约束、有效范围]
│   ├─ [字段2]：[约束、有效范围]
│   └─ ...
└─ 输出规范：
    ├─ [成功输出格式]
    ├─ [错误输出格式]
    └─ ...
```

### 阶段3：风险评估

在实施前识别潜在问题：

- **技术风险**：已知限制、潜在性能瓶颈
- **数据风险**：数据一致性、完整性、迁移问题
- **集成风险**：API 变更、依赖版本冲突
- **运营风险**：监控需求、调试挑战

### 阶段4：验证策略

定义如何验证正确性：

- **单元测试策略**：哪些内容需要单元测试？
- **集成测试策略**：如何测试集成？
- **手动测试用例**：关键用户旅程
- **验收标准**：何时算"完成"？

## 必问问题类别

规划时始终提出以下问题：

### 通用问题
- "此功能的精确用户旅程是什么？"
- "当 X 失败时会发生什么？"
- "系统应该如何处理 [边界情况]？"
- "性能期望是什么？"
- "谁需要批准此设计？"

### 数据问题
- "需要存储什么数据？"
- "如何处理数据验证？"
- "数据关系是什么？"
- "如何处理并发访问？"

### API/接口问题
- "精确的输入格式是什么？"
- "精确的输出格式是什么？"
- "错误代码及其含义是什么？"
- "需要什么认证/授权？"

### 用户体验问题
- "成功时用户应该看到什么？"
- "每种错误类型时用户应该看到什么？"
- "有什么加载状态需要处理？"
- "是否需要任何反馈或确认？"

### 部署问题
- "如何部署此功能？"
- "能否无停机部署？"
- "需要什么监控？"
- "回滚程序是什么？"

## 交付成果

使用此技能时，输出应包括：

1. **需求摘要**：完整理解需要构建什么
2. **设计树可视化**：系统的分层分解
3. **详细规格**：对每个功能包括：
   - 描述
   - 输入/输出规范
   - 错误处理
   - 边界情况
   - 测试场景
4. **风险矩阵**：已识别的风险及缓解策略
5. **实施计划**：带依赖关系的分步执行计划

## 应避免的反模式

- ❌ 未确认就做假设
- ❌ 因为"罕见"而跳过边界情况
- ❌ 延迟错误处理决策
- ❌ 编写模糊的规范
- ❌ 忽略性能影响
- ❌ 忘记安全影响
- ❌ 不考虑向后兼容性
- ❌ 规划时没有测试策略

## 应用示例

当用户说"添加用户认证"时，技能应展开为：

```
功能：用户认证
├─ 注册流程
│   ├─ 必填字段：邮箱、密码、确认密码
│   ├─ 密码要求：[具体指定]
│   ├─ 邮箱验证：[格式、唯一性检查]
│   ├─ 错误情况：
│   │   ├─ 密码过弱 → 显示具体要求
│   │   ├─ 邮箱重复 → 提供登录或更换邮箱
│   │   └─ 格式无效 → 显示行内错误
│   └─ 成功：[重定向、邮箱验证流程]
├─ 登录流程
│   ├─ 输入：邮箱、密码
│   ├─ 错误情况：
│   │   ├─ 凭证无效 → 通用消息
│   │   ├─ 账户锁定 → [显示锁定消息 + 恢复]
│   │   └─ 尝试过多 → 速率限制响应
│   └─ 成功：[重定向、会话创建]
├─ 密码重置流程
│   ├─ [详细分解]
└─ 安全要求
    ├─ 密码哈希算法
    ├─ 会话管理策略
    ├─ 速率限制阈值
    └─ CSRF 保护
```
