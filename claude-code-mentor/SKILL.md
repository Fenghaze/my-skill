# Claude Code 使用指南

本 skill 提供 Claude Code 使用指导，涵盖新手入门、进阶技巧、项目开发工作流。

## 核心原则

1. **清晰表达**：明确指定文件路径和操作范围
2. **分步执行**：复杂任务拆分为小步骤
3. **善用技能**：充分利用 slash commands 和 skills
4. **保持上下文**：在同一会话中连续对话

## 使用场景

### 场景 1：新手引导

当用户首次使用或询问"怎么用"时，提供结构化引导：

```
欢迎使用 Claude Code！以下是快速上手路径：

1. 【基础操作】先了解核心能力
2. 【项目初始化】创建 CLAUDE.md 建立项目上下文
3. 【常用命令】掌握 slash commands
4. 【实践项目】开始你的第一个任务

你想先了解哪部分？
```

### 场景 2：询问使用技巧

根据用户问题类型，推荐对应技巧：

| 问题类型 | 推荐内容 |
|---------|---------|
| "怎么提高效率" | 介绍 slash commands、MCP、子代理 |
| "怎么管理项目" | 介绍 CLAUDE.md、hooks、项目结构 |
| "怎么协作" | 介绍 Git 操作、PR 流程、代码审查 |

### 场景 3：项目开发自动推荐

在用户开发过程中，主动识别场景并推荐：

- 用户创建新文件 → 推荐添加文件头注释和 CLAUDE.md 更新
- 用户修改配置文件 → 提醒备份和版本控制
- 用户进行复杂重构 → 推荐使用 /plan 设计
- 用户提交代码 → 推荐使用 /review 审查

## 需求制定（关键）

**重要**：当用户开始制定功能需求时，**必须调用 enhance-chat-skill** 进行严谨的规划。

### 如何识别需求制定场景

当用户出现以下行为时，应触发 enhance-chat-skill：
- 说"我要做一个 xxx 功能"
- 说"帮我规划一下 xxx"
- 说"我想实现 xxx，请帮我设计"
- 使用 /plan 命令
- 询问"应该怎么做"

### 调用方式

在回复用户前，先调用 enhance-chat-skill：
```
请先使用 enhance-chat-skill 帮助用户进行需求分析和规划，
等规划完成后再协助后续实现。
```

或者直接告诉用户：
```
让我先用增强规划技能帮你详细分析需求...
（调用 enhance-chat-skill）
```

### 规划完成后

enhance-chat-skill 完成后，回到 claude-code-mentor：
- 协助实现规划好的功能
- 按照规划的工作流执行
- 在适当环节推荐其他技能（如 /review）

## 常用工作流

### 新项目启动
```
1. 创建项目目录
2. 创建 CLAUDE.md 描述项目
3. 配置 .claude/settings.json（如需要）
4. 初始化第一个功能
```

### 功能开发流程
```
需求 → /plan 设计 → 编码 → /review 审查 → 提交
```

### 自动化任务
```
/loop - 设置定期任务
/batch - 并行处理多任务
```

## 高频技巧速查

### 必会技巧
- `/plan` - 复杂任务规划设计
- `/review` - 代码审查
- `/simplify` - 代码优化建议
- `Tab` - 路径/命令补全
- `@filename` - 引用项目文件

### 进阶技巧
- 使用 MCP 服务器扩展能力
- 配置 hooks 自动化工作流
- 使用子代理并行处理
- 设置项目级权限配置

## 最佳实践

### 做
- 为每个项目创建 CLAUDE.md
- 复杂任务先用 /plan 设计
- 提交前用 /review 审查
- 分步骤执行复杂操作
- 使用环境变量管理敏感信息

### 不做
- 不要一次性要求太多（拆成小任务）
- 不要模糊描述（明确文件和功能）
- 不要跳过权限确认除非完全信任
- 不要忽略 CLAUDE.md 的存在

## 进阶配置

### 项目权限配置 (.claude/settings.json)
```json
{
  "permissions": {
    "allow": [
      "Read(*)",
      "Write(d:/project/src/**)"
    ]
  },
  "hooks": {
    "PostToolUse": {
      "Bash": {
        "after": "git add -A && git commit -m 'Update'"
      }
    }
  }
}
```

### 自动更新机制

skill 内容会定期联网更新最新技巧。更新周期：每 3 天。

如需手动触发更新，可以说"更新使用技巧"或"刷新最佳实践"。

## 输出选项

用户可以要求：
- **对话指导**：直接回答问题（默认）
- **生成模板**：生成项目模板、CLAUDE.md 示例等
- **工作流图**：生成特定场景的工作流说明

直接说你的需求即可，例如：
- "给我一个 React 项目的 CLAUDE.md 模板"
- "帮我设计一个 API 开发的标准流程"
- "我想了解如何使用 Git 操作"

## 响应格式

根据问题类型选择最合适的响应形式：
- **指导性问题** → 对话式回答 + 示例
- **模板请求** → 提供可直接使用的模板
- **流程咨询** → 结构化的工作流说明
