# 掌握程度评估标准

## 四级定义

### 了解 (Know)
听过概念，不清楚原理和应用场景。
**总结策略：** 概念定义 + 原理通俗解释 + 应用场景 + 完整代码示例 + 入门资源

### 熟悉 (Familiar)
能基本使用，但不了解底层机制和最佳实践。
**总结策略：** 核心原理 + 最佳实践 + 常见误区 + 进阶路径 + 实践建议

### 掌握 (Proficient)
能熟练使用，了解原理和适用场景。
**总结策略：** 深层原理 + 源码解析 + 变体对比 + 设计决策权衡 + 性能分析

### 精通 (Expert)
能设计实现，了解源码/底层机制，能向他人讲解。
**总结策略：** 架构思维 + 权衡分析 + 适用边界 + 演进方向 + 教学表达

## 内容对比表

| 维度 | 了解 | 熟悉 | 掌握 | 精通 |
|-----|------|------|------|------|
| 概念定义 | 详细 | 简要 | 跳过 | 跳过 |
| 应用场景 | 全面 | 重点 | 分析边界 | 权衡 |
| 原理机制 | 通俗 | 核心 | 深层 | 架构 |
| 代码示例 | 完整 | 典型 | 变体 | 设计 |
| 最佳实践 | 提及 | 重点 | 深入 | 权衡 |
| 常见误区 | 不讲 | 提醒 | 分析 | 避免 |

## 自测问题示例

**观察者模式是什么？**
- 了解：听说过，无法解释
- 熟悉：能说出"对象变化时通知其他对象"
- 掌握：能画结构图，写出 Subject/Observer
- 精通：能讨论优缺点，处理循环依赖

**数据库索引如何工作？**
- 了解：知道能让查询变快
- 熟悉：知道像书的目录
- 掌握：了解 B+ 树，最左前缀原则
- 精通：清楚存储引擎差异，优化大表

## 升级路径
- 了解 → 熟悉：多动手，实际项目中使用
- 熟悉 → 掌握：阅读源码，刻意练习
- 掌握 → 精通：系统性总结，教给他人
